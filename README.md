# 钢结构焊缝台账、无损检测和返修闭环平台

源提示词编号：13。覆盖构件与图纸焊缝台账、二维定位、焊工资质和检测比例预警、批量检测计划、缺陷记录、返修/复检状态、Apollo GraphQL 数据层、版本快照、签字锁定和完整追溯。

## 技术栈

Angular、PrimeNG、NgRx、Angular Router、RxJS、Apollo Angular、GraphQL、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62056

```bash
npm run build
```

## 锁定后的修订链

质量负责人签字锁定检测批次时，按计划内每条焊缝固化**资质版本、检测比例、缺陷与返修记录**（只读快照）。
锁定后的焊工资质补录、检测比例调整、复检结果更新都**只生成“待复核”修订**：原锁定结论立即失效并退回复核，原快照对象永不修改；复核通过后修订才落到工作数据，复核退回则修订作废、原锁定继续有效。

- 修订链：`锁定基线 REV-001 → REV-002（待复核/有效/已失效）→ …`，每条修订带 `parentId`、请求编号、变更前后值和完整条目快照。
- 并发保存：审核页“并发双保存”按钮演示两位审核人同版本同时签字——先到者成立，后到者收到版本冲突。
- 写入失败与重试：勾选“模拟下一次写入失败”后，写入不落任何记录并保留请求编号；横幅“用原请求编号重试”沿用同一编号，不会重复追加。
- 旧数据升级：GraphQL 旧台账经 `DataMigrationService` 按焊接时点有效资质补齐 `QV-xxx` 版本，返修次数展开为返修记录。
- 总览、焊缝地图、检测返修、审核锁定四页均通过统一横幅展示当前修订与失效原因。

```bash
npm run verify   # 34 项修订链规则断言（锁定/补录/调比/复检/并发/幂等/迁移）
```
